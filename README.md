# Python Test Automation Framework

UI test automation project built with Python, Selenium WebDriver, and pytest using the Page Object Model design pattern.

This project was created as part of the course [Automation Testing with Selenium and Python](https://stepik.org/course/575/info), module: [Page Object Model](https://stepik.org/lesson/199980/step/6?unit=174035).

## Tech Stack

- Python
- Selenium WebDriver
- pytest
- Page Object Model (POM)
